# Digest: personal web todo landscape (round 1)

Accessed 2026-11-04. Primary help pages only. No TAM.

## Products

- Todoist web: Today, P1–P4, descriptions, reminders, duplicate, Google/Outlook events in Today and Upcoming, day/week/month layouts.
- TickTick web: priority, pin, duration, reminders, duplicate, day/week/month/year, Google Calendar events in Today; progress percent on check items.
- Microsoft To Do web: My Day, importance star, notes, reminders, steps, All list; official help documents move between lists.
- Remember The Milk web: priority, time estimate, notes, reminders, smart lists (incomplete, priority, estimate, due).
- Google Tasks in Google Calendar web: description, subtasks, notifications, duration, day/week/month/year, other calendars on the same grid.

## Sourced gaps

- Todoist Today/Upcoming omit undated tasks; no year layout in the official layout list; duplicate omits comments and custom reminders.
- TickTick partial state is a percent (auto from check items); year view hides undated tasks; constant alarm is mobile; web reminder path documented as email.
- Google Tasks Pending list is uncompleted tasks from the past 365 days; documented settings have no priority field.
- Remember The Milk calendar is an external iCal of due-dated tasks only.
- Microsoft To Do official help: move, not copy.

## Unknown

Confirm-before-copy. Microsoft To Do day/week/month/year and other people’s fixed times inside To Do. Remember The Milk copy-between-lists.
